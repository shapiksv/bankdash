# BankDash

BankDash is a learning project: a banking dashboard built from the BankDash Figma UI kit, with a Java 25 / Spring Boot microservices backend (API Gateway, JWT auth, PostgreSQL, Kafka, Docker Compose) and a React + TypeScript frontend in the same monorepo.

- [UI analysis](docs/ui-analysis.md) — screens from the mockup, the data they show and the actions they offer.
- [Architecture](docs/architecture.md) — services, events, repository structure and the implementation plan.
